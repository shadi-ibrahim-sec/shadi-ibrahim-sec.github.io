Profile

Methodology over noise.

I am an Application Security Researcher and Web Penetration Tester focused on uncovering high-impact vulnerabilities that automated scanners miss — particularly broken access controls, multi-tenant isolation flaws, race conditions, and complex business-logic abuse.

Rather than relying solely on automated fuzzing, my workflow centers on understanding how an application actually works: inspecting compiled frontend JavaScript bundles, mapping undocumented API routes, and testing state transitions across distinct user roles.

Every engagement and responsible disclosure is conducted strictly within authorized scope and documented with clear remediation guidance for engineering teams.
